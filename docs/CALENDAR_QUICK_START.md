# Calendar Feature - Quick Start Guide

## 🚀 Getting Started

The Calendar tab is now fully functional! Here's everything you need to know to start using it.

## 📍 Location

Navigate to the **Calendar** tab in the bottom navigation bar (📅 icon).

## 🎯 Quick Actions

### View Your Schedule
1. Open the Calendar tab
2. See all your events at a glance
3. Switch between **Month** and **Week** views using the toggle buttons

### Add a New Event
1. Tap the **+ FAB** button (bottom-right corner)
2. Fill in event details:
   - Title (required)
   - Event type (based on your role)
   - Date and time
   - Recurring options (if needed)
3. Tap **Save**

### View Day's Events
1. Tap any date on the calendar
2. See all events for that day in a list
3. Tap an event to see more details

### Filter Events
1. Tap the **filter icon** (top-right)
2. Select/deselect event types:
   - Classes
   - Exams
   - Assignments
   - Personal
3. Tap **Apply**

## 👥 Role-Specific Features

### 🎓 Students
**You can:**
- View all class schedules
- See exam dates
- Track assignment deadlines
- Add personal events

**You cannot:**
- Edit class or exam events
- Create class events

**Quick Tip:** Use filters to focus on assignments or exams when studying!

### 👨‍🏫 Teachers
**You can:**
- Create class events for your courses
- Set up recurring class schedules
- Add personal events
- Enable attendance for class events

**Quick Tip:** Set up your entire semester schedule at once using recurring events!

#### How to Create a Recurring Class
1. Tap the + button
2. Select "Class" as event type
3. Choose your course
4. Set the date and time
5. Toggle "Recurring Event" ON
6. Select "Weekly"
7. Choose days (e.g., Mon, Wed, Fri)
8. Set end date (e.g., end of semester)
9. Enable attendance if needed
10. Save

### 👔 Admins
**You can:**
- Create all event types
- Add exams visible to all students
- Create global academic events
- Edit/delete any event

**Quick Tip:** Create exam events early so students can plan their study schedule!

### 👪 Parents
- **Read-only access** to your child's calendar
- View all class schedules and events
- No FAB button (cannot create events)

## 🎨 Understanding the Calendar

### Month View
- **Dots under dates**: Indicate events on that day
- **Colors**:
  - Black dot = Class
  - Red dot = Exam
  - Blue dot = Assignment
  - Green dot = Personal
- **Gray background**: Today's date
- **Black background**: Selected date

### Week View
- **Columns**: One for each day of the week
- **Cards**: Each event shown as a card with time
- **Scroll**: Swipe left/right to see more events
- **Recurring badge**: ↻ symbol indicates recurring event

### Event Cards
- **Left border color**: Indicates event type
- **Time**: Shows start and end time
- **Course name**: Shows if event is linked to a course
- **Attendance badge**: Shows if attendance tracking is enabled

## 🔄 Recurring Events Explained

### What are Recurring Events?
Events that repeat on a schedule (e.g., classes that happen every Monday and Wednesday).

### How They Work
1. You create **one event** with a recurrence pattern
2. The calendar **automatically shows** all occurrences
3. Example: "DBMS Lecture" every Mon/Wed from Jan 15 to May 15
   - You create it once
   - It appears ~30+ times on your calendar

### Recurrence Options
- **Daily**: Repeats every day
- **Weekly**: Repeats on specific days of the week
  - Select multiple days (Mon, Tue, Wed, etc.)
- **End Date**: Optional - set when recurring stops

## 📚 Assignment Integration

### Automatic Calendar Events
When a teacher creates an assignment:
1. Assignment is saved in the system
2. **Calendar event is automatically created**
3. Event titled: "{Assignment Title} - Due"
4. Event appears at the assignment due date/time
5. Event is linked to the course

### What This Means for You
- **Students**: You see all assignment deadlines on your calendar
- **Teachers**: No need to manually add assignment deadlines
- **Everyone**: Calendar stays in sync with assignments automatically

### If Assignment is Deleted
- The calendar event is **automatically deleted** too
- No orphaned events left behind

## 🎯 Navigation Tips

### Jump to Today
- Tap the **date text** in the header (between arrows)
- Instantly returns to current date

### Navigate Months
- Tap **left arrow** (◀) for previous month
- Tap **right arrow** (▶) for next month

### Navigate Weeks
- Switch to Week view
- Use arrow buttons to move week by week

### Pull to Refresh
- Pull down on the calendar to refresh events
- Ensures you have the latest data

## 🔍 Troubleshooting

### Events Not Showing?
1. Check your date range (month/week)
2. Check if filters are applied
3. Pull to refresh
4. Ensure you have internet connection

### Can't Create Event?
1. Check your role permissions
2. For class events, ensure course is selected
3. Ensure all required fields are filled
4. Check date/time are valid

### Recurring Events Not Appearing?
1. Check the end date (may have expired)
2. Ensure correct days are selected
3. Navigate to a date within the recurrence range

### Assignment Event Missing?
1. Wait a few seconds (real-time sync)
2. Pull to refresh
3. Check filters (Assignment type should be enabled)
4. Verify assignment was created successfully
