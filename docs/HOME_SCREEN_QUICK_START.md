# Home Screen - Quick Start Guide

## 🎯 Overview

The Home Screen is your dashboard - the first thing you see when opening AITIAN. It provides a personalized overview of your day, quick stats, and easy access to key features.

---

## 🚀 Getting Started

### First Time Opening the App
1. You'll land on the **Home** tab automatically
2. See your personalized greeting
3. Scroll to explore all sections
4. Tap any card or button to navigate

---

## 📱 What You'll See

### 1. **Greeting Header**
- Personalized greeting based on time of day
- Your name displayed
- Current date
- 🔔 Notification bell (shows pending items count)

### 2. **Quick Stats Cards** (Scroll Horizontally)
Your key metrics at a glance:

#### 👨‍🎓 Students See:
- **Attendance %** - Your current attendance (green if good, red if below 75%)
- **Pending Assignments** - How many assignments you haven't submitted
- **Enrolled Courses** - Total courses you're taking
- **Classes Today** - Number of classes scheduled today

#### 👨‍🏫 Teachers See:
- **Classes Today** - How many classes you're teaching today
- **Pending Gradings** - Assignments waiting to be graded
- **Total Students** - Number of students across your courses
- **Active Courses** - Courses you're currently teaching

#### 👔 Admins See:
- **Total Students** - All students in the system
- **Total Teachers** - All teachers in the system
- **Active Courses** - All active course instances
- **Active Users** - Combined active students and teachers

#### 👪 Parents See:
- **Child's Attendance** - Your child's attendance percentage
- **Pending Assignments** - Child's unsubmitted assignments
- **Classes Today** - Child's classes scheduled today
- **Performance** - Overall performance indicator

### 3. **Attendance Alert** ⚠️ (If Needed)
- Shows if attendance falls below 75%
- Red warning card with clear message
- Tap to view attendance details
- *Only visible to students and parents*

### 4. **Today's Schedule** 📅
- Timeline of today's classes
- **Next class** highlighted with badge
- Past classes shown with reduced opacity
- Shows: Time, Course name, Location
- ✓ Checkmark if attendance was marked
- Empty state if no classes today

### 5. **Upcoming Deadlines** 📝 (Students Only)
- Next 5 pending assignments
- Shows time until due:
  - "Due in 2 days"
  - "Due tomorrow"
  - "Due in 3 hours"
- **Overdue assignments** in RED with warning stripe
- Course name and assignment title
- Tap to view assignment details

### 6. **Quick Actions** ⚡
Grid of 4 action buttons for fast access:

#### 👨‍🎓 Student Actions:
- **View Timetable** → Opens Calendar
- **Assignments** → Opens Academics
- **Check Attendance** → Opens Academics
- **Announcements** → Opens News

#### 👨‍🏫 Teacher Actions:
- **Create Post** → Opens News
- **My Courses** → Opens Academics
- **Mark Attendance** → Opens Calendar
- **Grade Assignments** → Opens Academics

#### 👔 Admin Actions:
- **Manage Users** → Opens Profile
- **Manage Courses** → Opens Academics
- **View Reports** → Opens Profile
- **Send Announcement** → Opens News

#### 👪 Parent Actions:
- **Performance** → Opens Academics
- **View Schedule** → Opens Calendar
- **Attendance** → Opens Academics
- **Contact Teacher** → Opens News

### 7. **Recent Announcements** 📢
- Latest 3 posts from news feed
- 📌 Pinned posts shown first with badge
- Author name and timestamp
- Content preview
- Tap to read full announcement

---

## 🎮 How to Use

### Navigate Around
- **Tap stat cards** → Go to relevant section
- **Tap class cards** → Open calendar
- **Tap assignments** → View assignment details
- **Tap announcements** → Read full post
- **Tap quick actions** → Navigate to feature
- **Tap "See All"** → View complete list

### Refresh Data
1. **Pull down** on the screen
2. Release when you see the refresh indicator
3. Data will reload
4. Stats update automatically

### Check Your Day
1. Look at "Today's Schedule" section
2. See your next class (highlighted)
3. Note the time and location
4. Check if any assignments are due soon

### Stay Informed
1. Scroll to "Recent Announcements"
2. Read important updates
3. Tap to see full details
4. Check pinned posts first (marked with 📌)

## 🎨 Understanding the Colors

- **Green** 🟢 - Good status (attendance ≥75%, on time)
- **Red** 🔴 - Alerts (attendance <75%, overdue)
- **Blue** 🔵 - Information (assignments, courses)
- **Purple** 🟣 - Communication (announcements, posts)
- **Orange** 🟠 - Calendar events
- **Black** ⚫ - Primary actions

## 🆘 Troubleshooting

### "Loading..." Takes Too Long
- Check your internet connection
- Pull down to refresh
- Close and reopen the app
- Check if other tabs load

### Stats Show "0" or Wrong Numbers
- Pull down to refresh
- Wait a few seconds (data syncing)
- Check if you're enrolled in courses
- Verify your profile is complete

### No Classes Showing
- Check if it's a holiday/weekend
- Verify you're enrolled in courses
- Check Calendar tab for full schedule
- Refresh the screen

### Assignments Not Appearing
- Check if you have any assignments
- Look in Academics tab for full list
- Pull to refresh
- Verify course enrollment

### Attendance Alert Always Shows
- Your attendance might be below 75%
- Check full attendance in Academics tab
- Attend classes regularly to improve
- Contact your teacher if incorrect

## 📊 Understanding Your Stats

### Attendance Percentage
- **90-100%** 🌟 - Excellent! Keep it up!
- **75-89%** ✅ - Good, but try to improve
- **Below 75%** ⚠️ - Warning! Attend more classes
- **Formula**: (Present / Total Classes) × 100

### Pending Assignments
- Shows only **unsubmitted** assignments
- Includes overdue ones
- Number updates in real-time
- Tap to view and submit

### Classes Today
- Counts scheduled classes for today
- Includes past and upcoming
- Updates at midnight
- Next class highlighted specially
